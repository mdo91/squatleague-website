Squat League Pro

Le paiement est débité de votre compte Apple après tout essai gratuit éligible. Les abonnements se renouvellent automatiquement, sauf annulation dans les paramètres de votre abonnement Apple avant le renouvellement. Vos efforts en mémoire

L'historique est stocké sur cet appareil. Les dates restent le jour où vous avez terminé chaque entraînement. Les totaux d'activité sont enregistrés sur cet appareil. Game Center préserve la progression des réalisations signalées ; Les répétitions et les séquences de différents appareils ne sont pas combinées.
